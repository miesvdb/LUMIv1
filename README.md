# Mijn Leven — PWA prototype

Dit is een mobiele webapp/PWA met:
- Vandaag-dashboard
- Budgetten en uitgaven
- Maaltijdplanning
- Boodschappenlijst
- Agenda
- Schoonmaakschema
- Lokale opslag op het toestel

## Testen op computer
Open `index.html` voor een snelle preview. Voor volledige PWA-functionaliteit (installeren/offline) moet de map via HTTPS of localhost worden geserveerd.

Bijvoorbeeld met Python:
`python -m http.server 8000`

Open daarna:
`http://localhost:8000`

## Op telefoon installeren
Zet deze map online via bijvoorbeeld GitHub Pages, Netlify of Vercel.
Open de website daarna op je telefoon:
- iPhone: Safari → Deel → Zet op beginscherm
- Android: Chrome → menu → App installeren / Toevoegen aan startscherm

Alle gegevens worden in deze prototypeversie lokaal in de browser opgeslagen.
